# Discover Lesotho — Tourism Website

## Pages
- `index.html` — Home page
- `destinations.html` — Tourist destinations
- `accommodation.html` — Accommodation
- `activities.html` — Activities and FAQ accordion
- `gallery.html` — Interactive gallery with modal and previous/next controls
- `contact.html` — Registration/booking enquiry form with JavaScript validation

## Files
- `css/style.css` — Custom CSS3 design and responsive styles
- `js/script.js` — Gallery interaction, form validation and footer year
- `images/` — Place to store downloaded project images if you replace the remote demo images

## How to run
1. Extract the ZIP file.
2. Open the `lesotho_tourism_website` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use Live Server.
4. An internet connection is required for Bootstrap CDN and the demo photos.
5. Test all six pages, the mobile navbar, the activity FAQ accordion, the gallery modal and the booking form.

## Assignment features demonstrated
- HTML5 semantic elements, headings, paragraphs, lists, links, images and descriptive alt text
- External CSS stylesheet with colours, typography, spacing, box model, cards, shadows, hover effects and transitions
- Bootstrap 5 responsive container/row/column layout and responsive breakpoints
- Bootstrap navbar, cards, accordion, modal, alerts, buttons and forms
- JavaScript DOM manipulation, gallery image selection, next/previous controls, lightbox/modal and form validation
- HTML5 input types, required fields, validation feedback and a success message
- Consistent navigation and footer across all six interconnected pages

## Important limitations before submission
- This is a front-end student demonstration. The booking form validates in the browser but does not send or save bookings; a backend or approved form service would be needed for real submissions.
- Demo images are loaded from Unsplash URLs and are illustrative, not guaranteed to depict the named Lesotho location. Replace them with authentic, properly credited Lesotho photos if your lecturer expects location-specific evidence.
- Check the lecturer's instructions for required hosting and GitHub submission. Upload all six HTML files, `css/style.css`, `js/script.js`, and any local assets to GitHub, then publish the site using GitHub Pages or the hosting method specified by your lecturer.
- Before submission, test every page and verify image loading and links on both desktop and mobile.
